# LM1 Keystroke Lab

Virtual BA II Plus-style calculator with the CFA Level I LM1 equation cards (Eq. 1–21 plus two extras).

Run locally:

    pip install -r requirements.txt
    streamlit run app.py

Deploy: push this folder to GitHub, then on share.streamlit.io choose New app → this repo → app.py.
